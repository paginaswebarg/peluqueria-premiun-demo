# Peluquería premium — demo

Sitio web estático de demostración, propuesta comercial no oficial. No corresponde a un salón específico.

## Archivos
- `index.html`: contenido
- `styles.css`: diseño adaptable
- `script.js`: menú móvil

Las imágenes son ilustrativas y se cargan desde Unsplash. Sustituirlas por fotografías autorizadas del salón antes de publicar como sitio oficial. El correo `contacto@ejemplo.com` es ilustrativo.

Para publicarlo gratuitamente en GitHub Pages, configurar Settings > Pages > Deploy from a branch > main / (root).
